## Open questions that do not block the first increment

- Which educators will review detailed presentations and relationships?
- Which source tradition supplies the first full activity sequence?
- What license should apply to original code and original educational explanations? Do not assume third-party source content can be relicensed.
- Is cross-device ledger synchronization necessary after the local version proves useful?
- Which languages and accessibility needs should be prioritized after the first usable release?

Do not silently promote a proposal to accepted. Record the reason and authorization when a decision changes. This log contains product decisions, not personal conversations or private-instance details.
